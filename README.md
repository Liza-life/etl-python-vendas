# 🚀 Projeto ETL em Python – Pipeline de Vendas

Este projeto demonstra a construção de um **pipeline ETL (Extract, Transform, Load)** utilizando Python, simulando um cenário real de **Engenharia de Dados**, com foco em organização, qualidade dos dados e monitoramento.

O pipeline consolida dados de vendas a partir de arquivos CSV, aplica regras de transformação e carrega os dados em um banco analítico pronto para análises e BI.

---

## 🎯 Objetivo do Projeto

- Extrair dados de múltiplas fontes (CSV)
- Tratar e enriquecer os dados com regras de negócio
- Aplicar validações básicas de qualidade de dados
- Registrar o processamento com logging estruturado
- Disponibilizar os dados em banco analítico (SQLite)

---

## 🛠️ Tecnologias Utilizadas

- Python 3
- Pandas
- SQLAlchemy
- SQLite
- Logging
- Virtual Environment (venv)
